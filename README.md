# EliteGear

Page vitrine d'une boutique fictive de périphériques gaming. L'exercice : un carrousel en 3D
dont la rotation suit la position de défilement de la page.

En ligne : https://dunandchatellet.fr/EliteGear/EliteGear.html

## Ce que ça fait

- Carrousel de produits en perspective, piloté au défilement
- Mise en page qui s'adapte du téléphone au grand écran
- Sections présentation, produits et contact

## Comment c'est fait

HTML, CSS et JavaScript, sans dépendance.

| Fichier | Rôle |
| --- | --- |
| `EliteGear.html` | La page |
| `style.css` | Mise en page, perspective 3D, points de rupture |
| `script.js` | Rotation du carrousel selon le défilement |

Les marques et les photos de produits servent de décor : c'est un exercice de mise en page,
pas un vrai site marchand.
